iPad에서 홈 화면 앱을 삭제하거나 Safari 데이터를 정리하면 저장 데이터가 사라질 수 있습니다. 정기적으로 JSON 백업을 권장합니다.

GitHub Pages 설치

  1. 이 폴더의 모든 파일을 GitHub 저장소에 업로드합니다.
  2. Settings → Pages → Deploy from a branch를 선택합니다.
  3. Branch는 main, Folder는 /root를 선택합니다.
  4. 생성된 https://아이디.github.io/저장소명/ 주소를 iPad Safari에서 엽니다.
  5. 공유 버튼 → 홈 화면에 추가를 누릅니다.
